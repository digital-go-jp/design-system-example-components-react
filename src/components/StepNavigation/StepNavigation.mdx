## 仕様

### コンポーネント構成

- `StepNavigation`: ルートコンテナ。向き・サイズを管理する。`asChild` で `<nav>` への切り替えが可能
- `StepNavigationList`: ステップ一覧を包む `<ul>`
- `StepNavigationStep`: 各ステップの `<li>`。状態・位置属性を管理する
- `StepNavigationStepHeader`: ステップのヘッダー。`asChild` で `<a>`/`<button>` への切り替えが可能。スクリーンリーダー向け「ステップ」テキストを自動挿入
- `StepNavigationNumber`: 番号の丸要素
- `StepNavigationStateIndicator`: 完了・編集中・エラーの状態アイコンとラベル。`StepNavigationStep` の `state` に応じて表示内容が自動で切り替わる
- `StepNavigationTitle`: ステップのタイトル
- `StepNavigationDescription`: ステップの説明文

## 使い方

### 基本的な使い方

```tsx
<StepNavigation orientation="horizontal" size="normal">
  <p className="sr-only">全3ステップ中、1ステップ目まで到達済み</p>
  <StepNavigationList>
    <StepNavigationStep state="reached" first aria-current="true">
      <StepNavigationStepHeader>
        <StepNavigationNumber>1</StepNavigationNumber>
        <StepNavigationTitle>ステップのタイトル</StepNavigationTitle>
      </StepNavigationStepHeader>
      <StepNavigationDescription>ステップの説明が入ります。</StepNavigationDescription>
    </StepNavigationStep>
    <StepNavigationStep>
      <StepNavigationStepHeader>
        <StepNavigationNumber>2</StepNavigationNumber>
        <StepNavigationTitle>ステップのタイトル</StepNavigationTitle>
      </StepNavigationStepHeader>
    </StepNavigationStep>
    <StepNavigationStep last>
      <StepNavigationStepHeader>
        <StepNavigationNumber>3</StepNavigationNumber>
        <StepNavigationTitle>ステップのタイトル</StepNavigationTitle>
      </StepNavigationStepHeader>
    </StepNavigationStep>
  </StepNavigationList>
</StepNavigation>
```

### 現在のステップを示す

現在のステップには `aria-current="true"` を設定します。

```tsx
<StepNavigationStep state="reached" aria-current="true">
  ...
</StepNavigationStep>
```

### 状態アイコンを表示する

`completed`、`editing`、`error` 状態では、`StepNavigationNumber` の中に `StepNavigationStateIndicator` を配置して、番号の右上に状態アイコンを表示できます。`state` props に `StepNavigationStep` と同じ状態を渡すと、対応するアイコンとラベルが表示されます。対応する状態でなければ何も描画されません。

#### 完了状態

```tsx
<StepNavigationNumber>
  1
  <StepNavigationStateIndicator state="completed" />
</StepNavigationNumber>
```

#### 編集中状態

```tsx
<StepNavigationNumber>
  1
  <StepNavigationStateIndicator state="editing" />
</StepNavigationNumber>
```

#### エラー状態

```tsx
<StepNavigationNumber>
  1
  <StepNavigationStateIndicator state="error" />
</StepNavigationNumber>
```

### リンク付きで使用する（ナビゲーションとして）

ルートを `<nav>` にするには `asChild` を使い、`aria-label` を設定します。各ステップのヘッダーは `StepNavigationStepHeader asChild` で `<a>` に変更します。

```tsx
<StepNavigation asChild orientation="horizontal" size="normal">
  <nav aria-label="ステップ">
    <p className="sr-only">全3ステップ中、2ステップ目まで到達済み</p>
    <StepNavigationList>
      <StepNavigationStep state="completed" first>
        <StepNavigationStepHeader asChild>
          <a href="/step1">
            <StepNavigationNumber>
              1
              <StepNavigationStateIndicator state="completed" />
            </StepNavigationNumber>
            <StepNavigationTitle>ステップのタイトル</StepNavigationTitle>
          </a>
        </StepNavigationStepHeader>
      </StepNavigationStep>
    </StepNavigationList>
  </nav>
</StepNavigation>
```

### ステップをボタンにする

```tsx
<StepNavigationStepHeader asChild>
  <button type="button" onClick={() => goToStep(1)}>
    <StepNavigationNumber>1</StepNavigationNumber>
    <StepNavigationTitle>ステップのタイトル</StepNavigationTitle>
  </button>
</StepNavigationStepHeader>
```

### 番号のみで使用する

タイトルと説明を省略し、番号のみのステップナビゲーションにできます。

```tsx
<StepNavigationStep state="reached" first aria-current="true">
  <StepNavigationStepHeader>
    <StepNavigationNumber>1</StepNavigationNumber>
  </StepNavigationStepHeader>
</StepNavigationStep>
```

### ステップ幅をカスタマイズする（水平方向のみ）

水平方向のステップナビゲーションでは、CSS カスタムプロパティでステップの幅を調整できます。

```tsx
<StepNavigation
  orientation="horizontal"
  style={{ '--step-width': '200', '--step-min-width': '120' } as React.CSSProperties}
>
  ...
</StepNavigation>
```
